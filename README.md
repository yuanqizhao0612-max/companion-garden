# 陪伴花园 V0.2

面向银发用户的移动端三消与家庭花园原型。V0.2 的核心是：三消创造“今天的成就”，花园积累“长期的成就与关系”。

## 本轮完成

- 依据 V0.2 视觉设计重构任务书重新设计首页、游戏、结算和花园四个核心页面
- 统一为奶油底色、暖棕文字、樱粉强调、柔和圆角卡片和克制阴影的治愈系视觉语言
- 五种棋子改为轮廓各异的矢量花朵；即使降低饱和度，也能靠形状区分玫瑰、向日葵、郁金香、雏菊和绣球
- 手机端棋盘扩展到页面边缘，花朵视觉尺寸提升约 20%，仍保持 6×6 棋盘完整可见
- 建立独立 Game Feel 模块：点击跳起、流畅交换、无效操作轻摇、花朵绽放与花瓣飘散
- 三连、四连、五连采用递进动画和音阶；Combo 随连锁次数升调，并配合克制的轻触震动
- 完成关卡先淡出棋盘并显示“今天又照顾好了小院”，未完成使用“还差一点点”的继续思考文案
- 首页突出“开始今天”和“看看花园”，花园页强化家庭小院的长期成长叙事
- 30 个独立关卡配置；前 10 关有单独主题、目标、步数、障碍和提示
- 每关 1–3 种指定花朵目标，不再只计算总消除数
- 条纹花、彩虹花、花束三类特殊棋子
- 石块障碍和需要两次消除的覆盖花朵
- 无倒计时、无效交换不扣步、无解棋盘自动重排
- 完整家庭小院：房子、两类树、三类花、路径、长椅、篱笆、池塘、玩家人物
- 花朵、房屋、树木、路径按完成局数与连续使用天数渐进成长
- 三种玩家基础形象，本地保存；预留 `familyMembers`
- V0.1 本地数据自动迁移到 V0.2
- 支持 320px 屏幕、正文 18px、关键触控区域至少 44×44px

花朵棋子使用随任务提供的视觉参考图作为已确认风格来源；家庭小院使用项目已有场景截图整理为响应式位图资产。界面图标统一使用 Phosphor 图标库。

## 本地运行

```bash
pnpm install
pnpm dev
```

验证：

```bash
pnpm test
pnpm build
```

2026-07-29 实际结果：4 个测试文件、29 项测试全部通过；TypeScript 检查和 Vite 生产构建成功。

## 开发工具

在开发地址追加 `?preview=1` 可显示 1–30 关选择器、通关/未通关结果预览和花园 1–5 阶段成长预览；生产版本不会显示。控制台可运行 `resetCompanionGarden()` 重置本机试玩数据。

## 结构

- `src/levels.ts`：30 关独立配置
- `src/game/core.ts`：棋盘、匹配、特殊棋子、障碍、下落和重排
- `src/game/feedback.ts`：三连、四连、五连和 Combo 的反馈分级
- `src/composables/useMatchGame.ts`：关卡状态与反馈节奏
- `src/composables/useGameAudio.ts`：短促、柔和的程序化音效与轻触反馈
- `src/composables/useGarden.ts`：成长规则、本地保存和 V0.1 数据迁移
- `src/components/GardenScene.vue`：家庭小院成长场景切换
- `src/**/*.test.ts`：29 项自动化测试
- `LEVEL_DESIGN.md`：前 10 关配置与设计说明
- `design-qa.md`：参考图对照、手机端截图与视觉验收记录

## 当前边界

本版本不含登录、云同步、共享花园、家庭成员互动、聊天、付费、排行榜、广告和复杂换装。进度只保存在当前浏览器设备中。
